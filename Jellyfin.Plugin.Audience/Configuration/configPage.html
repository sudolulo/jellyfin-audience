Audience

Repairs ratings Jellyfin cannot parse, and tags the items a reduced-library profile should see.

When unchecked the task still appears in Scheduled Tasks but does nothing.

Rating repair

Rewrites foreign board ratings to their US equivalent, for example Singapore M18 to TV-MA and Spain TP to TV-G. A rating Jellyfin cannot parse is treated as unrated, which means it stays visible to every profile including one with an age ceiling. Ratings are never guessed from genre or synopsis; anything unmapped is logged as a warning instead.

Audience tagging

Set a user's Allowed Tags to this tag to reduce what they see. Allowed Tags fails closed, so new content is invisible to that user until this task tags it.
Lowercase with no spaces is safest: tag matching normalises the value and then compares it ordinally.
US ladder: 0 G and TV-G, 7 TV-Y7, 10 PG and TV-PG, 13 PG-13, 14 TV-14, 17 R and TV-MA. Inclusive, so 14 admits TV-14 itself.
Unrated items are admitted only above this community rating. This is a weak gate on obscure titles, where a perfect score can rest on a handful of votes.
Remember every item this task has tagged. If the tag is later removed by hand, treat that as a deliberate decision and never re-apply it. Turning this off makes each run undo your curation.
